Practice repository for **#90DaysOfDevOps** — Days 40–45 (GitHub Actions).

- Days 40–41: workflow basics, triggers, matrix
- Day 42: GitHub-hosted vs self-hosted runners, labels
- Day 43: jobs, steps, env vars, outputs, conditionals
- Day 44: secrets, artifacts, caching
- Day 45: Docker build & publish CI/CD

Self-hosted workflow runs on a Linux runner labelled `my-linux-runner`.

```bash
gh workflow list
gh run watch
```
